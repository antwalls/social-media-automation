# Plantilla Instagram

Usa esta plantilla como estructura base para crear posts de Instagram.
Adapta el formato (imagen / carrusel / reel) según el tema.

---

- [ ] Imagen única
- [ ] Carrusel (especifica nº de slides)
- [ ] Reel (usa template de TikTok para el guión)

## Checklist antes de guardar en Notion

- [ ] La primera línea funciona como gancho sola
- [ ] Caption tiene menos de 2200 caracteres
- [ ] Hay entre 15-25 hashtags
- [ ] El CTA es específico (no "clic en el enlace")
- [ ] Descripción visual clara para diseñar la imagen
