# Skill: Guías de Estilo por Canal

Esta skill documenta las normas de tono, formato y estilo para cada canal de contenido. Todos los agentes deben leer y aplicar estas guías al generar sus drafts.

## Principios Globales (todos los canales)

- **Idioma**: Español neutro (entendible en España y Latinoamérica)
- **Tono**: Cercano, directo, sin corporativismo
- **Verdad**: No inventar datos, estadísticas o citas sin fuente
- **Valor**: Cada pieza debe aportar algo útil, entretenido o inspirador
- **CTA**: Toda pieza debe tener un llamado a la acción claro

---

## 📧 Newsletter

| Elemento | Especificación |
|----------|---------------|
| **Longitud** | 400-700 palabras |
| **Tono** | Conversacional, como email de un amigo inteligente |
| **Estructura** | Subject → Intro gancho → Desarrollo → CTA → Firma |
| **Subject** | Máx 50 caracteres, con emoji, curiosidad o número |
| **Preview text** | 80-100 caracteres, completa el subject |
| **Párrafos** | Cortos (2-4 líneas máx) |
| **Listas** | Máx 5 puntos por lista |
| **CTA** | Un CTA principal, texto en primera persona ("Quiero ver más") |
| **Firma** | Nombre del autor/marca + enlace a web |

## 📸 Instagram

| Elemento | Especificación |
|----------|---------------|
| **Caption** | Máx 2200 caracteres. Los primeros 125 son clave (before "more") |
| **Tono** | Inspiracional, directo, con personalidad |
| **Estructura** | Gancho (línea 1) → Desarrollo (3-5 puntos) → CTA → Hashtags |
| **Hashtags** | 15-25 hashtags. Mix de grandes (#marketing), medios (#marketingdigital) y nicho |
| **Emojis** | Estratégicos, no excesivos. Máx 1-2 por párrafo |
| **Descripción visual** | 2-3 líneas describiendo la imagen o carrusel sugerido |
| **Stories CTA** | Opcional: texto corto para historia relacionada |
| **Formato carrusel** | Si es carrusel: título de cada slide (máx 7 slides) |

## 🎵 TikTok / Reels

| Elemento | Especificación |
|----------|---------------|
| **Duración** | Script para 30-60 segundos (≈75-150 palabras habladas) |
| **Tono** | Enérgico, sorprendente, conversacional |
| **Hook** | Primeross 3 segundos CRÍTICOS: pregunta, afirmación polémica o dato chocante |
| **Estructura** | Hook (0-3s) → Problema/Promesa (3-10s) → Desarrollo (10-50s) → CTA (50-60s) |
| **Ritmo** | Frases cortas. Una idea por frase. |
| **Descripción visual** | Indicaciones de escena, texto en pantalla, transiciones |
| **Hashtags** | 5-10 hashtags relevantes en la descripción del vídeo |
| **Caption** | Máx 150 caracteres en la descripción del vídeo |

## ✍️ Blog

| Elemento | Especificación |
|----------|---------------|
| **Longitud** | 800-1500 palabras |
| **Tono** | Informativo pero accesible, con ejemplos reales |
| **Estructura** | H1 (título SEO) → Intro → H2 secciones → Conclusión → CTA |
| **SEO** | Palabra clave principal en H1, intro, un H2 y conclusión |
| **Meta description** | 150-160 caracteres con keyword y propuesta de valor |
| **Slug** | Corto, con keyword, sin stop words |
| **Párrafos** | Máx 3-4 líneas. Usa negritas para ideas clave |
| **Imágenes** | Sugiere alt text descriptivo para cada imagen |
| **CTA final** | Una acción clara al terminar el artículo |
| **Tags** | 3-5 tags de categoría |
